# Оферта для cooleso.ru

`oferta.html` — новая страница публичной оферты по макету Figma «Oferta» (Desktop 1440 и Mobile 390). Это готовый блок для Tilda: стили, разметка и скрипт в одном файле. Всё лежит внутри `#koleso-offer`, остальной сайт не задевается.

С картой (`map/`) не связано: публикация на GitHub Pages берёт только `map/`.

## Как поставить на сайт

1. Tilda → проект cooleso.ru → страница «Договор оферты» (`/oferta_koleso`).
2. Удалить старые блоки оферты: обложку с фото, заголовок «ДОГОВОР публичной оферты…», текстовый блок с разделами 1–12, блоки приложений №1 и №2 (заголовки, картинки, текст «5. Оплата первого взноса…»). Шапку, подвал, плашку cookies и существующие блоки «HTML-код» не трогать.
3. На место удалённых блоков добавить блок **T123 «HTML-код»** (раздел «Другое»).
4. Вставить в него всё содержимое `oferta.html`, сохранить, нажать «Опубликовать».

## Что внутри

- Резиновая вёрстка; на ширине до 1023 px — мобильная раскладка из макета.
- Содержание слева на компьютере и строка «Содержание документа» на телефоне, обе с подсветкой текущего раздела. Учитывают закреплённую шапку Tilda.
- Печать (Ctrl+P / «Сохранить в PDF») — только текст оферты, без шапки и подвала сайта.
- Шрифты Manrope и Inter грузятся с Google Fonts.
