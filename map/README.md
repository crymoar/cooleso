# Карта мест занятий: новая версия

`index.html` (171 КБ, 47 КБ в gzip) — сама страница.
`metro-scheme.svg` (630 КБ, 50 КБ в gzip) — схема Яндекс Метро в том виде, в каком её рисует yandex.ru/metro: оба SVG-слоя сняты со страницы (`src/ylive.py`), убраны только значки вокзалов, аэропортов и достопримечательностей.

Важно: схема — данные Яндекса. Перед публикацией на сайте автошколы стоит проверить условия использования Яндекс Метро.
Если SVG хранится по другому адресу, перед подключением страницы задайте `window.KOLESO_SCHEME_URL`.

`?view=map` открывает страницу сразу на карте города, `?admin=1` показывает внутренние пометки «уточнить адрес».

## Что сделано

1. **Вес.** Страница с данными весит 171 КБ, данные ужаты с 2,5 МБ до 80 КБ. Схема вынесена в отдельный файл: геометрия очищена от текстового слоя, координаты округлены, файл прогнан через svgo. Карта города (MapLibre) загружается только при открытии вкладки «Карта города».
2. **Один шрифт.** Везде Inter Tight. По ширине он совпадает с подписями PDF (медиана 1,01, разброс ±4 %), поэтому подписи стоят на своих местах одним кеглем 10,8 и без растягивания.
3. **Подсветка при наведении на станцию:** линия станции целиком, соседи на ±3 перегона и всё в радиусе ~120 px (пятно). Остальное гаснет до 13 %. Карточка показывает линии, есть ли занятия и ближайшие площадки.
4. **Список мест** разбит на типы «У метро» (95) и «По адресу» (54). Есть фильтры МКПП/АКПП и МЦД/МЦК, поиск по станции, улице или линии. В карточке места — время пешком, кнопки «Как добраться» и «Яндекс Карты».
5. **Карта города:** светлая подложка с русскими подписями, линии метро и МЦД, кластеры. У выбранного адреса пунктиром показаны связи с ближайшими станциями.

## Куда двигаться дальше

- **Источник схемы.** У Яндекса публичного API схемы метро нет. Официальная схема Мосметро есть только в PDF. Варианты:
  - SVG-схемы с Wikimedia Commons (CC BY-SA, нужна атрибуция; проверить актуальность файла);
  - собственная векторная схема по координатам станций из открытых данных data.mos.ru (станции и входы в вестибюли) или OpenStreetMap. Это 60–100 КБ вместо 1,7 МБ, полный контроль над стилем, и подсветка работает по семантике линий, а не по цвету.
- Заменить справочник hh.ru на data.mos.ru или OSM: там точнее координаты и есть входы, поэтому время пешком считается до выхода.
- Хранить КПП (МКПП/АКПП) в исходной таблице для всех мест, включая адреса. Сейчас тип КПП берётся из старой карты и есть только у части станций.

## Пересборка

`src/` — шаблон и скрипты. `ymrender.py <scheme.json> <resources.json> <out.svg>` рисует схему из ответа Яндекса, `build_ym.py` привязывает к ней станции. `build_data.py data.json > data.min.json` сжимает данные. `build_scheme.py <dir>` строит подписи и отчёт. `assemble.py <dir> <out>` собирает `index.html`.

## Как выходят версии

1. Каждая доработка — отдельная ветка и pull request в `main`. В PR — описание, ссылка на предпросмотр и скриншоты проверки.
2. После проверки PR сливается в `main`. Сайт от этого не меняется.
3. Выкатка: Releases → «Draft a new release» → тег вида `v1.1.0` → «Generate release notes» → «Publish release».
   Action `.github/workflows/pages.yml` собирает сайт из этого тега и публикует его; номер версии появляется в подвале.
4. Откат: Actions → «Publish map» → «Run workflow» → указать прошлый тег, например `v1.0.0`.

Записи об изменениях — в `CHANGELOG.md`.

## Данные о местах занятий

Карта берёт места из `map/data/places.csv` — обычной таблицы. Её можно открыть в Excel или Google Таблицах, поправить или заменить целиком и сохранить как CSV (UTF-8; разделитель `;`, `,` или табуляция — определяется сам).

| Колонка | Что писать |
|---|---|
| `тип` | `метро`, `адрес`, `точка`, `офис`, `мото` |
| `название` | для метро — название станции, для адреса — адрес |
| `линия` | только если станций с таким названием несколько (например, `МЦД-1`) |
| `мкпп`, `акпп` | `да` или пусто; обязательно для метро, адреса и точки |
| `встреча` | `нет` — станция показывается только как ближайшая к адресу; пусто — инструктор встречает у станции |
| `широта`, `долгота` | для адреса и точки |
| `станции` | для адреса: `Тульская 5 мин 392 м, Шаболовская (МЦК) 9 мин`; метры можно не писать |
| `станция` | для офиса и мото — станция, у которой он находится |
| `сезон` | для мото: `лето`, `зима` или `круглый год` |
| `примечание` | для офиса — его адрес; для адреса — заметка, видна только в режиме `?admin=1` |

Станции, указанные у адресов, появляются на карте сами — отдельной строкой их добавлять не нужно. Коробку такая станция берёт от адресов, у которых она указана; если у станции есть своя строка с коробкой, главнее она.
Станция или адрес без коробки попадут в замечания `?admin=1`.
Адрес не показывается отдельным местом: он второй строкой у станций из своего столбца `станции`. Если столбец пуст, адрес привязывается к ближайшей станции по прямой (замечание в `?admin=1`).
Строки с ошибками (неизвестная станция, нет координат, непонятный тип) пропускаются; список замечаний виден, если открыть карту с `?admin=1`.
Дата «данные от …» в подвале — дата последнего изменения файла.

Вместо CSV можно положить `map/data/places.json` в прежнем формате — карта возьмёт его, если CSV нет.
Чтобы брать места с другого адреса, на странице, где встроена карта, перед ней задайте:
`<script>window.KOLESO_PLACES_URL='https://ваш-сайт/places.csv'</script>`

`map/data/metro.json` — справочник станций и линий и их положение на схеме; его править не нужно.
