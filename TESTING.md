# Тесты

Автотесты на Playwright (`tests/`). Они открывают страницу в настоящем Chromium — на десктопе и в мобильной раскладке — и проверяют, как она выглядит и ведёт себя.

## Запуск

```bash
npm ci
npx playwright install chromium
npm test                # оба проекта: desktop и mobile
npm run test:desktop
```

Локально тесты сами поднимают сервер на папке `map/`. Проверить уже опубликованный сайт:

```bash
BASE_URL=https://crymoar.github.io/cooleso/map/ npm test
```

## Правила

1. **Каждая ошибка — тест.** Исправление бага не принимается без теста, который на старой версии падает. Название теста содержит номер issue, например `(#14)`.
2. **Релиз только с зелёными тестами.** `pages.yml` сначала прогоняет `tests/`, и только потом публикует сайт; после публикации те же тесты идут по живому сайту.
3. **Issue закрывается после релиза**, когда исправление выпущено, тесты на него зелёные и на живом сайте проверка тоже прошла. В описании PR пишите `Refs #N`, а не `Fixes #N` — иначе GitHub закроет issue при слиянии, до релиза.
4. После правки `map/src/template.html` скопируйте его в `map/index.html` (проверяется тестом).
