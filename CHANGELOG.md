# История версий

## [v1.3.0] — 2026-11-13

### Добавлено
- Режим встраивания `?embed=1` для показа карты в iframe (сайт на Тильде). Без параметра карта работает как раньше; данные и код общие.
  - Телефон: карта занимает ровно высоту iframe, своей прокрутки у страницы нет. Схема сверху (45 %), ниже панель: поиск и фильтры закреплены, листается только список. Долистали список до конца — свайп листает страницу сайта.
  - Схема и карта города на телефоне двигаются двумя пальцами; одним пальцем листается страница, на карте появляется подсказка «Двигайте двумя пальцами». Тап по станции работает как раньше.
  - Компьютер: колесо мыши над картой листает страницу; масштаб — Ctrl/⌘ + колесо или кнопки +/−.
  - Выбор места не прокручивает окно: карточка открывается и листается внутри панели.
  - Все внешние ссылки открываются в новой вкладке; в подвале — «Открыть на весь экран».

### Исправлено
- Ссылка OpenStreetMap в подписи запасной подложки карты города открывается в новой вкладке.

### Техническое
- Тесты режима встраивания: `tests/embed.spec.js` (карта в iframe между двумя блоками по 600px, компьютер и iPhone 13).

### Исправлено
- Поиск находит мотоплощадку по адресу так же, как станцию по улице.

### Техническое
- Автотесты на Playwright (`tests/`, описание в `TESTING.md`): список, схема, кластеры, наведение, мобильная версия. Идут на каждый PR и на `main`.
- Релиз публикуется на сайт только после зелёных тестов; после публикации те же тесты идут по живому сайту.

## [v1.2.2] — 2026-11-12

### Исправлено
- Мотоплощадка в списке показывается как остальные места: станция, тег сезона рядом с названием, адрес второй строкой. Сортировка — по станции.

## [v1.2.1] — 2026-11-12

### Изменено
- Адрес больше не отдельное место. Место занятий — всегда станция с коробкой; адрес второй строкой: «Строгино · АКПП — ул. Таллинская, 20к3 · 11 мин пешком». Остальные адреса станции — в её карточке, каждый со своей коробкой.
- «Где встреча»: «Все / У метро / По адресу» — обе категории это станции, отличается место встречи. «Офис» убран из переключателя, офисы остаются метками.
- Поиск по улице находит станцию («Таллинская» → Строгино).
- Адрес, у которого нет станции в пешей доступности, привязывается к ближайшей станции по прямой; для Мытищ показано расстояние вместо времени пешком.
- Карта города: у выбранной станции — точки её адресов с подписями; легенда без «адреса» как отдельного места.

## [v1.2.0] — 2026-11-11

### Изменено
- У каждой станции и каждого адреса есть коробка: МКПП, АКПП или обе. Понятия «дополнительная станция» больше нет.
- Коробки адресов и станций сверены с выгрузкой инструкторов (по машинам). Станция в пешей доступности от адреса без своей строки с коробкой берёт коробку этого адреса.
- Правки по коробкам: Строгино — АКПП (Таллинская, 20к3), Академическая — МКПП и АКПП (Кедрова, 15), Тульская — только АКПП (Большая Тульская, 2), Нижегородская — МКПП, Селигерская — АКПП, Шаболовская — АКПП.
- «Мото» перенесено из «Где встреча» в «Коробку». Фильтры «Механика/Автомат» показывают и адреса.
- В списке у станции кружок цвета её линии и МКПП/АКПП рядом с названием; строка с названием ветки убрана.
- Кружки с числом на схеме окрашены по коробкам внутри (МКПП, АКПП, обе).
- Подсветка при наведении идёт по линии станции, а не по цвету (Новокосино больше не подсвечивает Солнцевскую ветку).
- Наводить можно на метку или подпись станции; область наведения — только они с небольшим запасом, анимация плавнее.
- Офис и занятия на одной станции (Достоевская) — одна метка, карточка показывает всё.

### Добавлено
- Мотоплощадки по сезонам (колонка `сезон`: лето, зима, круглый год): Люблинская, 42; Владыкино; Авиамоторная; Сходненская; Новокосино/Выхино; Ростокино; Юго-Западная; Ленинский проспект; Киевская; Нахимовский проспект.

### Исправлено
- На телефоне тап по точке открывает её карточку сразу под картой; «Все места» возвращает к списку на прежнее место, тап по пустому месту карты закрывает карточку.

## [v1.1.0] — 2026-11-11

### Добавлено
- Места занятий хранятся отдельно от страницы, в таблице `map/data/places.csv` (открывается в Excel и Google Таблицах). Её можно править или заменять целиком без изменения кода.
- Поддерживается и JSON (`map/data/places.json`), и внешний адрес файла через `window.KOLESO_PLACES_URL`.
- Строки с ошибками пропускаются, список замечаний виден в режиме `?admin=1`; если данные не загрузились, страница так и пишет.

### Изменено
- Справочник метро вынесен в `map/data/metro.json`; страница стала легче (146 КБ вместо 270 КБ).

## [v1.0.0] — 2026-11-11

Первая версия новой карты мест занятий (`map/`).

### Схема метро
- Схема Яндекс Метро, отрисованная как есть; убраны значки вокзалов, аэропортов, пригородов, номера линий, река и пунктиры пешеходных пересадок.
- Подписи станций — Inter Tight.
- Метки мест по коробке: МКПП, АКПП, обе, дополнительные станции, офис, мото; растут с масштабом.
- Близкие метки собираются в кружки с числом, как на карте города; клик по кружку приближает.
- Наведение на место занятий: подсветка его линии и карточка с коробкой и площадками рядом.

### Карта города
- Булавки «Колесо» и кружки-группы, как в исходной карте; линии метро выключены по умолчанию.

### Список и фильтры
- Фильтры «Где встреча» (метро, адрес, офис/мото) и «Коробка», галочка МЦД/МЦК, поиск.
- Выбор места в списке центрирует и приближает карту.

### Техническое
- Обе карты на Leaflet + Leaflet.markercluster.
- Версия показывается в подвале страницы.
- Сайт публикуется только при выходе релиза (`.github/workflows/pages.yml`).
